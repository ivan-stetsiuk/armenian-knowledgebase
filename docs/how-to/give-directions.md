# Give and ask directions

## Script

**You:** Ո՞ւր ես գնում։
*Where are you going?*

**Them:** Դեղատուն։ Իսկ դու որտեղի՞ց ես գալիս։
*To the pharmacy. And where are you coming from?*

**You:** Մարզասրահից։ Դեղատունը դպրոցի դիմաց է։ Գնա ուղիղ, հետո թեքվիր ձախ։
*From the gym. The pharmacy is across from the school. Go straight, then turn left.*

## Directions

| Armenian | English |
|---|---|
| Գնա ուղիղ։ | Go straight. |
| Թեքվիր աջ։ / Թեքվիր ձախ։ | Turn right. / Turn left. |
| Գնա ուղիղ, հետո թեքվիր ձախ։ | Go straight, then turn left. |
| աջ · ձախ · ուղիղ | right · left · straight |

## Where things are

Noun in the genitive + postposition.

| Armenian | English |
|---|---|
| Դպրոցի դիմաց մեծ այգի կա։ | Across from the school there is a big park. |
| Տան մոտ շատ մարդիկ կան։ | There are many people near the house. |
| Այշեն միշտ նստում է իմ կողքին։ | Ayshe always sits next to me. |
| Պայուսակը սեղանի վրա է։ | The bag is on the table. |
| Մահճակալի տակ ոչինչ չկա։ | There is nothing under the bed. |
| Մատիտը գրքի մեջ է։ | The pencil is in the book. |
| Նա քայլեց այգու միջով։ | She walked through the park. |
| Վերևում ոչ ոք չի ապրում։ | Nobody lives upstairs. |
| Ներքևում աղմուկ է։ | There is noise downstairs. |

## Going and coming

| Ո՞ւր ես գնում։ — Where to? | Որտեղի՞ց ես գալիս։ — Where from? |
|---|---|
| Տուն — home | Տնից — from home |
| Բանկ — to the bank | Բանկից — from the bank |
| Սրճարան — to the café | Սրճարանից — from the café |
| Աշխատանքի — to work | Աշխատանքից — from work |
| Դասի — to class | Դասից — from class |
| Հանդիպման — to a meeting | Հանդիպումից — from a meeting |

| Ինչո՞վ ես գնում։ — How are you getting there? | |
|---|---|
| Ոտքով — on foot | Մետրոյով — by metro |
| Տաքսիով — by taxi | Ավտոբուսով — by bus |
| Մեքենայով — by car | Գնացքով — by train |
