# Greetings and farewells

## Script

**You:** Բարև ձեզ։
*Hello. (polite, or to several people)*

**Them:** Ողջույն։ Ինչպե՞ս ես։
*Hi. How are you?*

**You:** Լավ եմ։ Իսկ դու՞։
*I am well. And you?*

…

**You:** Դե, ցտեսություն։ Կհանդիպենք հինգշաբթի։
*Well, goodbye. See you on Thursday.*

**Them:** Հաջողություն։ Մինչ վաղը։
*So long. See you tomorrow.*

## Greetings

| Armenian | English | When |
|---|---|---|
| Բարև ձեզ | Hello | polite, plural |
| Ողջույն | Hi | informal |
| Բարի լույս | Good morning | |
| Բարի օր | Good afternoon | |
| Բարի երեկո | Good evening | |
| Բարի գիշեր | Good night | |
| Բարի գալուստ | Welcome | |
| Բարի վերադարձ | Welcome back | |

## Farewells

| Armenian | English |
|---|---|
| Ցտեսություն | Goodbye |
| Հաջողություն / Հաջող | So long, good luck (formal / short) |
| Կհանդիպենք | See you |
| Կհանդիպենք հինգշաբթի (օրը) | See you on Thursday |
| Մինչ վաղը | See you tomorrow |
| Բարի ճանապարհ | Have a good journey |

## Wishes and courtesy

| Armenian | English |
|---|---|
| Բարի ախորժակ | Enjoy your meal |
| Անուշ / Անուշ լինի | Enjoy (said about food) |

| Ուրախ տոներ | Happy holidays |
| Կներես | Sorry (informal) |
| Խնդրում եմ | Please |
