# Armenian Knowledge Base

A personal reference for Eastern Armenian, built from lessons with a tutor (December 2025 onwards). It is not a textbook: it assumes the lesson happened and exists so that a rule or a word can be found again in ten seconds.

## Where to look

| You want to… | Go to |
|---|---|
| See what happened in a lesson, in order | [Lessons](lessons/index.md) |
| Look up a rule and its paradigm | [Grammar](grammar/index.md) |
| Find a word, or all words on a topic | [Vocabulary](vocabulary/index.md) |
| Say something now, with a ready script | [How-to](how-to/index.md) |
| Learn how this site is organised and how to add to it | [Guidelines](guidelines.md) |

Everything is in English. Russian appears only inside a translation when it renders an Armenian word more exactly than English does.

## Flashcards

Words and grammar transformations live in `data/vocab.tsv` and `data/grammar.tsv`. The Anki package `dist/armenian.apkg` and the Quizlet import files in `dist/quizlet/` are generated from them. Decks are named `hy::vocab::L07` (one per lesson) and `hy::grammar::<topic>`.

## Conventions

- Armenian is written in Armenian script only. No transliteration.
- `pron. հոքնած` marks a word whose spelling and pronunciation differ (հոգնած).
- *(spoken)* marks colloquial forms the tutor introduced as such, for example `ա` instead of `է`.
- Exercises show the prompts only. They are done on paper, not on this site.
