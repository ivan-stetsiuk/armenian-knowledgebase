## Grammar

!!! rule "There is / there are: կա, կան"

    **կա — there is (singular), կան — there are (plural); the place usually comes after.**

    :   Կան շատ հյուրեր իմ հյուրասենյակում։ — There are many guests in my living room.

    :   Իրանում կարմիր սունկ կա։ — In Iran there is a red mushroom.

    Full reference → [There is / there are](../grammar/there-is.md)

!!! rule "Present tense: -ում + auxiliary"

    **Verb stem + -ում + the auxiliary "to be": անել → Ես անում եմ — I do / I am doing.**

    :   Ի՞նչ ես անում։ — What are you doing? What do you do?

    :   Ես խոսում եմ հայերեն։ — I speak Armenian.

    Full reference → [Present tense](../grammar/present-tense.md)

!!! rule "Negative present: չ- on the auxiliary"

    **In the negative, the auxiliary takes չ- and moves in front of the verb: Ես չեմ անում — I am not doing.**

    :   Նրանք սովորաբար չեն խոսում հայերեն։ — They usually don't speak Armenian.

    :   Նա երբեք չի խոսում հայերեն։ — He/she never speaks Armenian.

    Full reference → [Negation](../grammar/negation.md)

!!! rule "Time adverbs with the present"

    **միշտ, սովորաբար, հաճախ, երբեք, երբեմն / մեկ-մեկ describe how often; they stand before the verb.**

    :   Մենք միշտ խոսում ենք հայերեն։ — We always speak Armenian.

    Full reference → [Present tense](../grammar/present-tense.md)

!!! rule "In a place: -ում"

    **-ում on a noun means "in": հյուրասենյակում — in the living room, Իրանում — in Iran.**

    :   Կան շատ հյուրեր իմ հյուրասենյակում։ — There are many guests in my living room.

    Full reference → [Locative -ում](../grammar/locative.md)

### Letter Մ մ [m]

![Մ մ](../assets/letters/men.png){ .letter }

- Սա իմ նկարն է, իսկ սա Արամի նկարն է։ — This is my picture, and this is Aram's picture.
- Սա իմ սանրն է, իսկ սա Արուսի սանրն է։ — This is my comb, and this is Arus's comb.

- Իրանում կարմիր սունկ կա։ — In Iran there is a red mushroom.
