## Grammar

!!! rule "Imperative of regular verbs"

    **-ել verbs: -ի՛ր (sg) / -ե՛ք (pl); -ալ verbs: -ա՛ (sg) / -ացե՛ք (pl). The prohibitive is մի՛ + the same form.**

    :   Գրել → գրի՛ր / գրե՛ք — write!; մի՛ գրիր / մի՛ գրեք — don't write!
    :   Կարդալ → կարդա՛ / կարդացե՛ք — read!; մի՛ կարդա / մի՛ կարդացեք — don't read!
    :   Նստել → նստի՛ր / նստե՛ք — sit down!; մի՛ նստիր — don't sit!

    Full reference → [Imperative](../grammar/imperative.md) · [Negation](../grammar/negation.md)
