## Grammar

!!! rule "Imperative of derivative verbs"

    **Verbs with the suffixes -ան, -են, -ն, -չ before -ալ/-ել drop the suffix: -անալ → -ացի՛ր / -ացե՛ք, -ենալ → -եցի՛ր / -եցե՛ք. Negative: մի՛ + the same form.**

    :   Հասկանալ → հասկացի՛ր / հասկացե՛ք — understand!; մի՛ հասկացիր / մի՛ հասկացեք — don't understand!
    :   Ծանոթանալ → ծանոթացի՛ր / ծանոթացե՛ք — get acquainted!
    :   Իմանալ → իմացի՛ր / իմացե՛ք — know!

    The same suffixes are dropped in the simple past and the perfect.

    Full reference → [Imperative](../grammar/imperative.md) · [Verbs in -անալ / -ենալ](../grammar/verbs-anal.md)

!!! rule "Simple past — first forms"

    **The simple past of խմել: խմեցի — I drank, խմեցիր — you drank.**

    :   Ես խմեցի։ — I drank.
    :   Քանի՞ հատ նեգրոնի խմեցիր։ — How many negronis did you drink?

    Full reference → [Simple past](../grammar/past-simple.md) · for "what were you doing" (Ի՞նչ էիր անում երեկ) see [Past of to be and the imperfect](../grammar/past-of-to-be.md)
