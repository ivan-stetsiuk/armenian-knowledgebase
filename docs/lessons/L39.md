## Grammar

!!! rule "Country → nationality → language → adjective"

    **Countries often end in -ստան, nationalities in -ացի / -ցի, languages in -երեն / -արեն, and the adjective "of that country" in -ական.**

    :   Հունաստան → հույն → հունարեն → հունական պար — Greece → Greek → Greek (language) → Greek dance
    :   Վրաստան → վրացի → վրացերեն → վրացական խինկալի — Georgia → Georgian → Georgian → Georgian khinkali

    Full table → [Countries, nationalities, languages](../grammar/nationality-suffixes.md)

## Exercises

### Exercise 1 · Complete the sentences (language)

*Example:* Ես հայ եմ։ Հայերեն լավ գիտեմ։

2. Դու ռուս ես։ Դու խոսում ես …։
3. Նա հույն է։ Նա խոսում է …։
4. Մենք կանադացի ենք։ Մենք խոսում ենք … և …։
5. Դուք ամերիկացի եք։ Խոսում եք …։
6. Նրանք ֆրանսիացի են։ Նրանք խոսում են …։
7. Մեհդին պարսիկ է։ Նա խոսում է …։
8. Դաթոն վրացի է։ Նա լավ է խոսում …։

### Exercise 2 · Fill in the corresponding word (nationality)

*Example:* Այս տղան ամերիկացի է, իսկ այս աղջիկը՝ գերմանացի։

2. Հանսը գերմանացի է, իսկ Ալիսը … (Ֆրանսիա)։
3. Իվանը ռուս է, իսկ Նենսին … (Ամերիկա)։
4. Միտոն ճապոնացի է, իսկ Ջոնը՝ … (Անգլիա)։
5. Դաթոն … (Վրաստան) է, իսկ Նատաշան … (Ռուսաստան)։
6. Այս տղան … (Չինաստան) է, իսկ այն տղան … (Հնդկաստան)։
7. Ալին … (Թուրքիա) է, իսկ Արմենը … (Հայաստան)։
8. Աբասը … (Սիրիա) է, իսկ Ժանը … (Ֆրանսիա)։

### Exercise 3 · Fill in the corresponding word (adjective)

*Example:* Այս այբուբենը հայկական է (Հայաստան)։

2. Իզաբելլան սիրում է պարել … պարեր (Իսպանիա)։
3. Աննան չի սիրում … խոհանոց (Իտալիա)։
4. Իվանը … անուն է (Ռուսաստան)։
5. Այս ազգանունը … է (Ճապոնիա)։
6. Սա … ուտելիք է (Չինաստան)։
7. Մենք շատ ենք սիրում … հաց (Ֆրանսիա)։
8. Իմ ընկերը սիրում է խմել … թեյ (Անգլիա)։
