## Spelling vs pronunciation

The tutor marks words whose spelling and sound differ. In most of them a voiced letter (բ, գ, դ, ձ, ջ) is pronounced like its voiceless partner (փ, ք, թ, ց, չ), usually after ր or before another consonant. Write the standard form; say the marked one.

:::details{title="All marked words"}

| Written | Pronounced |
|---|---|
| բարձր — high | բարցր |
| բարձ — pillow | բարց |
| հոգնած — tired | հոքնած |
| հոգնեցուցիչ — tiring | հոքնեցուցիչ |
| երբեք — never | երփեք |
| երբեմն — sometimes | երփեմըն |
| կարդալ — to read | կարթալ |
| մարդ — man, person | մարթ |
| բարդ — complex | բարթ |
| օդի — of the air | օթի |
| որդի — son | որթի |
| զուգարան — toilet | զուքարան |
| օգնել — to help | օքնել |
| ոգեշնչել — to inspire | ոքեշնչել |
| մտահոգված — concerned | մտահոքված |
| եղբայր — brother | եղպայր |
| անգամ — time, occasion | անքամ |
| երգել — to sing | երքել |
| թարգմանել — to translate | թարքմանել |
| համակարգիչ — computer | համակարքիչ |
| համբույր — kiss | համփույր |
| մեջք — back | մեչք |
| առաջարկել — to offer | առաչարկել |
| ընկերոջս — my friend's | ընկերոչս |
| դարձիր — become! | դարցիր |
:::

:::details{title="Hidden ը between consonants"}

The vowel ը is often not written but is pronounced between consonants (the tutor writes syllables with dashes).

| Written | Pronounced |
|---|---|
| գլխարկ — hat | գըլ-խարկ |
| սրճարան — cafe | սըր-ճարան |
| կրկնել — to repeat | կըր-կը-նել |
| դժվար — hard | դըժ-վար |
| հպարտ — proud | հը-պարտ |
| ցտեսություն — goodbye | ցը-տե-սություն |
| կհանդիպենք — see you | կը-հանդիպենք |
| ինքնավստահություն — self-confidence | ինք-նա-վըս-տա-հություն |
| դուստր — daughter | դուս-տըր |

This transitory ը is also why words like նկար and հրաշք count as more than one syllable in the plural (նկարներ, հրաշքներ) — see Plural.
:::

## My mistakes

:::pitfall{title="Recorded in lessons 3 and 4"}

<span class="ok">✓ դ and բ are different letters; so are մ and ն</span>
<span class="bad">✗ mixing դ–բ and մ–ն in handwriting (դ – բ / մ–ն խառնում ա)</span>

Slow down on the round letters: դ has an open bottom, բ a closed loop; ն is one arch, մ has the extra stroke.
:::
