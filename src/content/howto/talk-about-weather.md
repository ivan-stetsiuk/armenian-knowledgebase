title: "Talk about the weather"
---

## Script

**You:** Ի՞նչ եղանակ է այսօր։
*What is the weather like today?*

**Them:** Ահավոր շոգ է։ Արևոտ է։
*Terribly hot. It is sunny.*

**You:** Ինչքա՞ն է օդի ջերմաստիճանը այսօր։
*What is the air temperature today?*

**Them:** Օդի ջերմաստիճանը պլյուս երեսունհինգ է։
*The temperature is plus thirty-five.*

## Describing the weather

Pattern: adjective + է.

| Armenian | English |
|---|---|
| Շոգ է։ | It is hot. |
| Տաք է։ | It is warm. |
| Ցուրտ է։ | It is cold. |
| Զով է։ | It is cool. |
| Արևոտ / արևային է։ | It is sunny. |
| Անձրևոտ / անձրևային է։ | It is rainy. |
| Քամոտ է։ | It is windy. |
| Ձյունոտ է։ | It is snowy. |
| Մառախլապատ է։ | It is foggy. |
| Ամպամած է։ | It is cloudy. |
| Խոնավ է։ | It is humid. |
| Անձրև է գալիս։ / Ձյուն է գալիս։ | It is raining. / It is snowing. |
| Անձրև չի գալիս։ | It is not raining. |
| Անձրև է գալու։ | It is going to rain. |
| Կարծես ձյուն է գալու։ | It looks like it will snow. |
| Որոտում է։ | It is thundering. |
| Ինչ ուժեղ քամի է։ | What a strong wind. |
| Տասն աստիճան զրոյից ցածր է։ | It is ten degrees below zero. |
| Օդի ջերմաստիճանը մինուս հինգ է։ | The temperature is minus five. |
| Մրսում եմ։ | I am cold. |
| Տաք հագիր, ցուրտ է։ | Dress warmly, it is cold. |

## Seasons

| Question | Answer |
|---|---|
| Ո՞րն է տարվա քո սիրած եղանակը։ — What is your favourite season? | Գարունը։ / Ամառը։ / Աշունը։ / Ձմեռը։ |
| Ինչպիսի՞ն էր այս տարվա ամառը։ — What was this year's summer like? | Շատ շոգ էր։ — It was very hot. |

In spring գարնանը · in summer ամռանը · in autumn աշնանը · in winter ձմռանը.
