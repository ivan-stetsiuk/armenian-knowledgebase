## Grammar

::::rule{title="Possessive pronouns (recap)"}

**իմ, քո, նրա / իր, մեր, ձեր, նրանց / իրենց — one form for singular and plural nouns; spoken Armenian also uses իրա, իրանց.**

:::example
Դրանք իմ գրքերն են։ — Those are my books.
:::

Full reference → [Possessive pronouns](/grammar/possessive-pronouns/)
::::

::::rule{title="Demonstrative pronouns"}

**As nouns: սա / դա / նա (pl. սրանք / դրանք / նրանք); as adjectives: այս / այդ / այն + noun + ը/ն, the same form before singular and plural nouns.**

:::example
Ի՞նչ է սա։ Սա գիրք է։ — What is this? This is a book.  
Այս գիրքը — this book · Այս գրքերը — these books
:::

Full reference → [Demonstratives](/grammar/demonstratives/)
::::

::::rule{title="Ինչո՞վ / Ինչո՞ւ / Ե՞րբ / Ո՞ւմ հետ"}

**Ինչո՞վ (by what) is answered by noun + -ով (մետրոյով — by metro); Ինչո՞ւ (why) by infinitive + -ու expressing purpose (ուտելու — in order to eat); Ե՞րբ (when) by a time word; Ո՞ւմ հետ (with whom) by noun + հետ.**

:::example
Ինչո՞վ ես գնում։ — How are you getting there? · Ոտքով։ — On foot.  
Ինչո՞ւ ես գնում։ — Why are you going? · Խաղալու։ — To play.
:::

Full reference → [Question words](/grammar/question-words/) · [Instrumental -ով](/grammar/instrumental/)
::::
